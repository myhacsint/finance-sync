# Security

Bitte keine Zugangsdaten, Kontoauszüge, Wallet-Adressen oder vollständigen
API-Antworten in Issues einstellen. Sicherheitsmeldungen sollen über einen
privaten Security Advisory des späteren GitHub-Repositories erfolgen.

Das Container-Image wird ausschließlich aus diesem Quellbaum gebaut. Persönliche
Konfiguration liegt außerhalb des Images in Unraid-Volumes und Secret-Dateien.
